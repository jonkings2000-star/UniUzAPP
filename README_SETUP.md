# UniUZ v4

One Flask server serves both the Mini App and API.

Railway Variables:
BOT_TOKEN=...
ADMIN_ID=...
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-4.1-mini
WEB_APP_URL=https://uniuz-production.up.railway.app

Start command is provided by Procfile: `python server.py`.

Telegram BotFather Mini App URL must point to:
https://uniuz-production.up.railway.app/
